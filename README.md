### Injection Methodology

- **Heap Fragmentation Monitors** – Detect and dissolve memory leaks before they manifest as crashes.

## 🔧 Installation & Initialization

**Prerequisites:**
- A 64-bit operating system (Windows 10+ recommended)
- The target game installed with original files intact
- At least 1 GB of free memory for the game to breathe

**Setup Steps:**
1. Download the suite archive from the official distribution mirror.
2. Extract the contents to any directory of your choice (the folder is portable—no system files touched).
3. Launch the launcher executable. It will detect the game's installation path automatically.
4. Start the game normally. The suite will hook itself during the initial loading screen.
5. Verify the in-world HUD appears (default key: `INSERT`).

**Updates** are delivered bi-weekly by default, with optional nightly previews for adventurers.
